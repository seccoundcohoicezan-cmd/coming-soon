# coming-soon

Landing page **Coming Soon · Roadtrip YCS 2026**: bus karikatur berjalan di jalan Bali, sopir melambai, info hadiah (8 unit HP + Mercedes).

Situs statis satu file (`index.html` + `assets/img/`), tanpa build. Bisa langsung dipasang di Vercel, Netlify, atau GitHub Pages.

Jalankan lokal:

```bash
python3 -m http.server 8080
# buka http://localhost:8080
```

Aset:
- `bus-*.webp` + `tangan-*.webp`: maskot bus dipisah jadi badan dan tangan (tangan dianimasikan melambai), latar transparan.
- `jalan-bali-*.webp`: latar jalan Bali, garis jalan dianimasikan agar bus terasa berjalan.
